# azad

Support and privacy pages for azad, a private workout and food log for iPhone and Android.

- Questions: https://esfand-r.github.io/azad-app/
- Privacy policy: https://esfand-r.github.io/azad-app/privacy/
- Help: open an issue. Issues are public, so please don't post your workouts, food or anything personal.

The app's code is not in this repository. These pages are generated from it; please don't edit them here.
